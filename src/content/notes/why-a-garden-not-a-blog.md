Devblogs make me freeze. The implicit contract is "this is publishable" — which
means polished, which means I don't write anything. A garden is different. The
roughness is the point. A note can be one sentence and a question mark.

The model I'm copying is [[andy-matuschak-style-notes]]. Dense interlinking,
visible growth states, no obligation to be done. Some notes will mature into
[[evergreen-notes]]. Most won't.

What I want this to do:

- Capture in-progress thinking without ceremony
- Link aggressively so ideas accrete connections over time
- Embed live experiments (Rust/WASM, web apps) inline with prose
- Let an agent draft routine updates — with visible provenance

What I want it to NOT do:

- Look like marketing
- Pretend to be finished
- Hide the agent's hand when the agent wrote it
